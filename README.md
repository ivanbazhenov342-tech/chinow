# Шаньцзян

Игра для русскоязычных начинающих изучать китайский. Статический сайт с Three.js, рассчитанный на GitHub Pages.

## Что реализовано

- Начальная история «От вокзала до чайной», 12 последовательных задач.
- Оформление графического романа: рисованные материалы, ступенчатый свет и тонкие контуры. Вокзальная площадь окружена двухэтажными фасадами, балконами, переулками и дворами. Фасад плавно становится прозрачным, когда закрывает героя.
- Персонажи Microsoft Rocketbox со скелетной анимацией, ограниченной цветовой палитрой и контуром. Портреты собеседников нарисованы в стиле окружения. Объёмные вывески сохраняют положение при вращении камеры.
- Вращаемая 3D-диорама, перемещение касанием с поиском пути вокруг зданий, жители, поезд, пар, фонари.
- Карта 12 районов и 72 учебные миссии с тематикой от основ до A2.
- 663 уникальных слова. Их изучение начинается с поиска записок в 3D-сцене, затем игрок идёт к собеседнику.
- 72 просьбы жителей в истории подготовки Праздника фонарей. Выполненные миссии постепенно украшают район.
- Диалоги, объяснения, сборка фраз, задания на чтение и слух, дневник. Повторение использует слова в предложениях и возвращает ошибки.
- Прописи для 138 знаков с анимацией, обводкой и самостоятельным письмом с проверкой черт.
- Сохранение между этапами урока, повторение слов, экспорт и импорт прогресса.

Все 663 слова и фразы и 72 диалога имеют аудио. 529 записей слов принадлежат носителю, 134 слова, 72 диалога и реплика Линь озвучены голосом Ladaisy через ElevenLabs. Текст всех диалогов и 123 слов после генерации сверен распознаванием речи. Разговоры можно слушать в обычном и замедленном темпе. Происхождение файлов и сверенные тексты указаны в audio/sources.json.

Курс охватывает темы A2. Завершение заданий внутри игры само по себе не является сертификацией уровня владения языком.

## Разработка и публикация

Проект работает без сборки и ключей. Для локального запуска используйте статический HTTP-сервер в корне проекта. Например, `python3 -m http.server 4173`. Откройте http://localhost:4173.

Проверки запускаются командами `npm ci` и `npm test`. Они проверяют цепочки миссий и поиск пути с подменой WebGL-отрисовки и интерфейса распознавания черт. Проверяются также независимое скрытие закрывающих героя фасадов и неподвижность вывесок при повороте камеры. Визуальную проверку и письмо пальцем нужно дополнительно проходить в браузере.

Для проверки компиляции и линковки графических программ без браузера: `node tools/check-shader-inputs.mjs`, затем `MESA_SHADER_CACHE_DIR=/tmp/mesa-shanjiang python tools/check-shaders.py`. Нужны системные libEGL и libGL; проверяются атлас, растительность и материалы/контуры всех трёх моделей. Статичные детали фасадов, поезда и торговой тележки объединяются по материалу, подвижные фонари остаются отдельными.

GitHub Actions запускает проверки и публикует файлы из main на GitHub Pages. Все игровые ресурсы, кроме необязательных веб-шрифтов, находятся в репозитории.
