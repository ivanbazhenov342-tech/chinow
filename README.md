# Шаньцзян

Игра для русскоязычных начинающих изучать китайский. Статический сайт с Three.js, рассчитанный на GitHub Pages.

## Что реализовано

- Начальная история «От вокзала до чайной», 12 последовательных задач.
- Вращаемая 3D-диорама, перемещение касанием с поиском пути вокруг зданий, жители, поезд, пар, фонари.
- Карта 12 районов и 72 учебные миссии с тематикой от основ до A2.
- 663 уникальных слова, диалоги, объяснения, сборка фраз, задания на чтение и слух, дневник.
- Прописи для 138 знаков с анимацией, обводкой и самостоятельным письмом с проверкой черт.
- Сохранение между этапами урока, повторение слов, экспорт и импорт прогресса.

529 слов имеют записи носителя. У остальных слов доступны пиньинь и значение, запись отмечена как готовящаяся. Линь озвучена голосом Ladaisy через ElevenLabs. Большинство диалогов курса пока представлены текстом.

Курс охватывает темы A2. Завершение заданий внутри игры само по себе не является сертификацией уровня владения языком.

## Разработка и публикация

Проект работает без сборки и ключей. Для локального запуска используйте статический HTTP-сервер в корне проекта. Например, `python3 -m http.server 4173`. Откройте http://localhost:4173.

Проверки запускаются командами `npm ci` и `npm test`. Они проверяют цепочки миссий и поиск пути с подменой WebGL-отрисовки и интерфейса распознавания черт. Визуальную проверку и письмо пальцем нужно дополнительно проходить в браузере.

GitHub Actions запускает проверки и публикует файлы из main на GitHub Pages. Все игровые ресурсы, кроме необязательных веб-шрифтов, находятся в репозитории.
