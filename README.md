# Шаньцзян · Восточный вокзал
Первый игровой эпизод курса китайского. Подойдите к дежурному, прослушайте 出口, найдите выход и встречающую с синим зонтом. Касание земли перемещает героя, горизонтальный свайп поворачивает ортографическую камеру. Кнопки дублируют действия. Прогресс хранится на устройстве.

Для локального запуска выполните `python3 -m http.server 8000` в этой папке и откройте http://localhost:8000. GitHub Pages обслуживает корень main. Сборка и ключи не требуются.
